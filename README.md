# Tutorial profissional — ETEC / Centro Paula Souza

Site estático em Bootstrap 5.3 para publicação no Vercel.

## Páginas

- `index.html` — capa, identificação, objetivos e arquitetura
- `01-crud.html` — CRUD
- `02-api.html` — API JSON
- `03-render.html` — GitHub + Render + Firebase
- `04-expo.html` — React Native + Expo Snack
- `deploy_nodejs_vercel_render.pdf` — tutorial complementar de Deploy no Render
- `css/style.css` — identidade visual e responsividade

## Publicação no Vercel

1. Crie um repositório no GitHub.
2. Envie todos os arquivos e a pasta `css`.
3. Importe o repositório no Vercel.
4. Framework Preset: `Other`.
5. Build Command: vazio.
6. Output Directory: `.`
7. Faça o Deploy.

## Personalização

Na capa, altere:
- DISCIPLINA / COMPONENTE
- PROFESSOR
- TURMA

O campo de professor está propositalmente em branco para você preencher antes do deploy.

## Observação

O conteúdo técnico foi estruturado a partir do material do projeto e do roteiro de deploy fornecido, incluindo `process.env.PORT`, `FIREBASE_SERVICE_ACCOUNT`, `npm install`, `npm start` e a regra de não publicar `serviceAccountKey.json`.
