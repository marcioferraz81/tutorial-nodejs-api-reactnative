Crie e teste a API JSON

A API será a ponte entre o back-end e o aplicativo React Native.

Conceito: o navegador pode receber HTML/EJS; o aplicativo precisa receber dados em JSON.
01

Rota da API

router.get("/api", controller.api);

Assim, dentro da rota de categorias, teremos:

/categorias/api
02

Controller

exports.api = async (req, res) => {
  try {
    const categorias = await model.listar();
    res.json(categorias);
  } catch (erro) {
    console.error(erro);
    res.status(500).json({
      erro: "Erro ao buscar categorias"
    });
  }
};
03

Teste no navegador

http://localhost:3000/categorias/api
Exemplo de resposta
[
  {
    "id": "-Oabc123",
    "nome": "INFORMÁTICA",
    "descricao": "Cursos de informática"
  }
]
04

Confira o CORS

No app.js, a aplicação precisa permitir requisições externas:

const cors = require("cors");
app.use(cors());

Isso permitirá que o Expo Snack faça fetch() da API publicada.
